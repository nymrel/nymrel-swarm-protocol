# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The Nymrel engineering team takes security vulnerabilities seriously.

If you discover a security vulnerability in `@nymrel/swarm-protocol` or `nymrel_swarm_protocol`, please do NOT disclose it publicly on GitHub issues.

Instead, please send an encrypted or private report to:
**contact@nymrel.com**

Please include:
1. Description of the vulnerability.
2. Steps to reproduce the vulnerability (code snippet or reproduction scenario).
3. Potential impact on concurrent agents or filesystem operations.
4. Proposed mitigation or patch if available.

We will acknowledge receipt within 24 hours and provide a timeline for remediation.
